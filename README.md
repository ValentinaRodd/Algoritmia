## Cómo usar este repositorio

1. Entra a la carpeta del taller que quieras revisar.
2. Lee primero el enunciado o el README del taller.
3. Revisa los ejercicios resueltos y compáralos con tu propio trabajo.
4. Los talleres se pueden hacer en orden, porque cada uno construye sobre el anterior.
